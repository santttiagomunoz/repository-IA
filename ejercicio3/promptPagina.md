# PROMPT — PRESENTACIÓN PROFESIONAL DEL PROYECTO NUTRIBUDGET

Actúa como un experto en diseño de presentaciones ejecutivas, comunicación tecnológica, arquitectura de software y storytelling de productos digitales.

Necesito que diseñes una presentación profesional para exponer el proyecto **NutriBudget**, una aplicación web FoodTech enfocada en la planificación alimentaria, la optimización del presupuesto doméstico y el aprovechamiento de los alimentos disponibles.

La presentación debe estar construida a partir de la documentación proporcionada: SRS de NutriBudget versión 1.0, análisis técnico, propuesta de arquitectura, definición del MVP y especificaciones de diseño y desarrollo.

## 1. OBJETIVO DE LA PRESENTACIÓN

Explicar de manera clara, visual y profesional:

- Qué es NutriBudget.
- Qué problemática busca solucionar.
- Por qué surge la necesidad de esta aplicación.
- A quién está dirigida.
- Cuál es su propuesta de valor.
- Cómo funciona la aplicación.
- Cuáles son sus principales funcionalidades.
- Cómo está estructurada técnicamente.
- Qué tecnologías se utilizarán.
- Cómo se organiza su base de datos.
- Cuáles son sus reglas de negocio más importantes.
- Qué incluye el MVP.
- Cómo se desarrollará y validará el producto.

La exposición debe transmitir que NutriBudget no es simplemente una idea o un recetario digital, sino una propuesta de producto de software respaldada por un proceso de análisis, especificación de requisitos, diseño UX/UI y planificación arquitectónica.

BACKEND:
Java + Spring Boot.
Responsable de autenticación, reglas de negocio, cálculos, generación de menús y gestión de datos.

BASE DE DATOS:
PostgreSQL.
Responsable del almacenamiento de usuarios, ingredientes, inventarios, recetas, presupuestos, menús y compras.

Comunicación:
API REST mediante solicitudes HTTP.

Incluir:
Spring Security, Spring Data JPA, Hibernate y Swagger/OpenAPI.
